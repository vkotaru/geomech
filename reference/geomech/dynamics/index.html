    LinearizedSystem(rows=list(), states=list(), dstates=list(), inputs=list(), M=dict(), A=dict(), B=dict(), row_types=dict(), col_types=dict()) dataclass ¶

    Linearized dynamics M δẋ = A δx + B δu as symbolic blocks.

    Attributes¶

    rows : list[str] Ordered row labels: kinematic rows first ("kin:" + str(var), one per configuration variable in SystemVariables order), then the dynamic rows labelled by the compute_eom keys. states : list[Expr] Perturbation symbols of δx: configuration perturbations in SystemVariables order, then velocity perturbations in the same order. dstates : list[Expr] [s.t_diff() for s in states]. inputs : list[Expr] [u.delta() for u in inputs]. M, A, B : dict[str, dict[str, Expr]] M[row][str(dstate)], A[row][str(state)], B[row][str(input_variation)]. Dense: every (row, column) pair is present. Block shapes follow row type × column type (vector × vector → 3×3 Matrix, scalar × vector → 1×3 Transpose(Vector), vector × scalar → 3×1 Vector, scalar × scalar → Scalar); zero blocks are the library zero constants of that shape. row_types, col_types : dict[str, ExprType] Expression type of each row and of each column symbol (used by block_shape).

    def block_shape(self, row, col) -> tuple[int, int]:
    """Shape of the block at (*row*, *col*); *col* may be a symbol or its ``str``."""
    row_key = row if isinstance(row, str) else str(row)
    col_key = col if isinstance(col, str) else str(col)
    if row_key not in self.row_types:
        raise KeyError(f"LinearizedSystem: unknown row '{row_key}'")
    if col_key not in self.col_types:
        raise KeyError(f"LinearizedSystem: unknown column '{col_key}'")
    n_rows = 1 if self.row_types[row_key] == ExprType.SCALAR else 3
    n_cols = 1 if self.col_types[col_key] == ExprType.SCALAR else 3
    return (n_rows, n_cols)

    StandardFormEquation(M=dict(), f=None, G=dict()) dataclass ¶

    Standard form for one EOM equation.

    Σ M[a_j] * a_j + f + Σ G[u_k] * u_k = 0

    Attributes¶

    M : dict[str, Expr] Mass/inertia coefficient for each acceleration variable. f : Expr Nonlinear terms (Coriolis, gravity, etc.) — scalar or vector. G : dict[str, Expr] Input influence coefficient for each input variable.

    SystemVariables(scalars=list(), vectors=list(), matrices=list()) dataclass ¶

    Configuration variables that define the degrees of freedom.

    scalars: scalar configuration variables (Scalar) vectors: vector configuration variables (Vector, S2) matrices: matrix configuration variables (SO3)

    Each group is a list (or tuple); a bare leaf raises TypeError. An empty SystemVariables() can be built (check_eom accepts it), but compute_eom raises ValueError for it: a system with no degree of freedom has no equation.

    compute_eom(lagrangian, inf_work, variables, params=(), *, trace=None) ¶

    Compute equations of motion using the principle of least action.

    Stages, in the order the code runs them (docs/pipeline.md has one paragraph per stage; the bracketed names are the EOMTrace stage names):

    1. [dL] the variation of the Lagrangian, [dW] the virtual work, and [dS] the infinitesimal action integral δS = δL + δW
    2. [manifold_rules] apply_manifold_rules: δω and δΩ replaced by their kinematic expansions (S², SO(3))
    3. [simplify] full_simplify (expand once, then simplify to a fixed point)
    4. integration by parts against the time derivative of each variation vector: [ibp.prepare] expand + full_simplify, then per target [ibp.collect[t]] (rotate each term so the target is the left operand of a Dot), [ibp.integrate[t]] (one IBP pass) and [ibp.simplify[t]]; [ibp] is the result
    5. [expand]
    6. per variation vector: extract_linear_coeff [raw[ξ]], then full_simplify [equation[ξ]]

    trace (keyword only) is an EOMTrace: it is filled with every stage as the pipeline runs, so after an exception it holds the stages before the failure and trace.failed_at names the stage that raised (trace.summary(), trace.show("simplify")). The trace is cleared first, so a reused trace holds this run only. Without a trace, and with the geomech logger not at DEBUG, nothing is recorded. With GEOMECH_DEBUG=1 each stage is logged and check_tree runs on the inputs and the equations.

    An extraction failure is re-raised with the same exception type and the pipeline context: the variation vector, and when a time derivative of a variation vector survived integration by parts, the term it survived in.

    inf_work may be None or 0 for a conservative system. It must be linear in the variation vectors themselves: a time derivative of a listed variation vector in inf_work (Dot(x.t_diff().delta(), f), Dot(ξ.t_diff(), f)) raises ValueError. variables must list at least one configuration variable (ValueError "no configuration variables" otherwise; this check runs last, so a Lagrangian that holds a symbol first fails the stray-variation check below); params must be a sequence of leaves (TypeError).

    Every symbol in lagrangian and inf_work is one of three things: a configuration variable (listed in variables, varied by Hamilton's principle), a constant (attr=["Constant"]), or a prescribed time-varying parameter declared in params (a plain non-constant Scalar/Vector/Matrix leaf such as a cable length l(t): its rate l̇ appears in the equations, its variation δl is not free and is dropped). A variation symbol that survives extraction and belongs to none of these (δx of an unlisted x, ξ/δω of an unlisted S2 point, …) raises ValueError naming it: before, such terms were dropped silently and the system lost a degree of freedom. numeric.check_eom takes the same params. A param printed like a different leaf of lagrangian or inf_work (a constant l of L declared as Scalar("l")) raises ValueError: it would have no effect. to_standard_form accepts the result (a param's rate stays in f, the param itself in M); linearize does not support prescribed parameters yet and raises AlgebraicError on the δl term.

    def compute_eom(
    lagrangian: Expr,
    inf_work: Expr | int | float | None,
    variables: SystemVariables,
    params: Sequence[Expr] = (),
    *,
    trace: EOMTrace | None = None,
) -> dict[str, tuple[Expr, Expr]]:
    """Compute equations of motion using the principle of least action.

    Stages, in the order the code runs them (``docs/pipeline.md`` has one paragraph per
    stage; the bracketed names are the ``EOMTrace`` stage names):

    1. ``[dL]`` the variation of the Lagrangian, ``[dW]`` the virtual work, and
       ``[dS]`` the infinitesimal action integral δS = δL + δW
    2. ``[manifold_rules]`` ``apply_manifold_rules``: δω and δΩ replaced by their
       kinematic expansions (S², SO(3))
    3. ``[simplify]`` ``full_simplify`` (expand once, then simplify to a fixed point)
    4. integration by parts against the time derivative of each variation vector:
       ``[ibp.prepare]`` expand + full_simplify, then per target ``[ibp.collect[t]]``
       (rotate each term so the target is the left operand of a ``Dot``),
       ``[ibp.integrate[t]]`` (one IBP pass) and ``[ibp.simplify[t]]``; ``[ibp]`` is
       the result
    5. ``[expand]``
    6. per variation vector: ``extract_linear_coeff`` ``[raw[ξ]]``, then
       ``full_simplify`` ``[equation[ξ]]``

    ``trace`` (keyword only) is an ``EOMTrace``: it is filled with every stage as the
    pipeline runs, so after an exception it holds the stages before the failure and
    ``trace.failed_at`` names the stage that raised (``trace.summary()``,
    ``trace.show("simplify")``). The trace is cleared first, so a reused trace holds
    this run only. Without a trace, and with the
    ``geomech`` logger not at ``DEBUG``, nothing is recorded. With ``GEOMECH_DEBUG=1``
    each stage is logged and ``check_tree`` runs on the inputs and the equations.

    An extraction failure is re-raised with the same exception type and the pipeline
    context: the variation vector, and when a time derivative of a variation vector
    survived integration by parts, the term it survived in.

    ``inf_work`` may be ``None`` or ``0`` for a conservative system. It must be linear in
    the variation vectors themselves: a time derivative of a listed variation vector in
    ``inf_work`` (``Dot(x.t_diff().delta(), f)``, ``Dot(ξ.t_diff(), f)``) raises
    ``ValueError``. ``variables`` must list at least one configuration variable
    (``ValueError`` "no configuration variables" otherwise; this check runs last, so a
    Lagrangian that holds a symbol first fails the stray-variation check below);
    ``params`` must be a sequence of leaves (``TypeError``).

    Every symbol in ``lagrangian`` and ``inf_work`` is one of three things: a
    configuration variable (listed in ``variables``, varied by Hamilton's principle), a
    constant (``attr=["Constant"]``), or a prescribed time-varying parameter declared in
    ``params`` (a plain non-constant ``Scalar``/``Vector``/``Matrix`` leaf such as a cable
    length ``l(t)``: its rate ``l̇`` appears in the equations, its variation ``δl`` is not
    free and is dropped). A variation symbol that survives extraction and belongs to none
    of these (``δx`` of an unlisted ``x``, ``ξ``/``δω`` of an unlisted ``S2`` point, …)
    raises ``ValueError`` naming it: before, such terms were dropped silently and the
    system lost a degree of freedom. ``numeric.check_eom`` takes the same ``params``. A
    param printed like a different leaf of ``lagrangian`` or ``inf_work`` (a constant
    ``l`` of ``L`` declared as ``Scalar("l")``) raises ``ValueError``: it would have no
    effect.
    ``to_standard_form`` accepts the result (a param's rate stays in ``f``, the param
    itself in ``M``); ``linearize`` does not support prescribed parameters yet and raises
    ``AlgebraicError`` on the ``δl`` term.
    """
    if trace is not None:
        trace._reset()
    stage = "validation"
    try:
        check_variables(variables)
        if not isinstance(params, (Expr, str)) and hasattr(params, "__iter__"):
            params = list(params)  # a generator is read twice (here and the clash check)
        param_names = _check_params(params, variables)
        if isinstance(inf_work, bool):
            raise TypeError(
                "compute_eom: inf_work must be a scalar expression, None or 0, got bool"
                f" {inf_work}"
            )
        if inf_work is None or (isinstance(inf_work, (int, float)) and inf_work == 0):
            inf_work = Zero
        _check_scalar_input("lagrangian", lagrangian)
        _check_scalar_input("inf_work", inf_work)
        check_symbol_clash(
            params,
            [lagrangian, inf_work],
            "compute_eom",
            role="params entry",
            what="a prescribed parameter",
            where="the Lagrangian or the virtual work",
        )

        # gather variation vectors and their time derivatives
        variation_vectors = []
        variation_vector_dots = []

        for s in variables.scalars:
            ds = s.delta()  # Variation(scalar) — scalar type
            variation_vectors.append(ds)
            variation_vector_dots.append(ds.t_diff())

        for vec in variables.vectors:
            x = vec.get_variation_vector()
            variation_vectors.append(x)
            variation_vector_dots.append(x.t_diff())

        for mat in variables.matrices:
            x = mat.get_variation_vector()
            variation_vectors.append(x)
            variation_vector_dots.append(x.t_diff())

        allowed = {str(v) for v in variation_vectors}
        _check_virtual_work(inf_work, variables, allowed)

        debug = debug_enabled()
        if debug:
            check_tree(lagrangian)
            check_tree(inf_work)
        record = stage_recorder(trace, "compute_eom")
        if trace is not None:
            trace.variation_vectors = list(variation_vectors)
            trace.ibp_targets = list(variation_vector_dots)

        # variation of the Lagrangian
        stage = "dL"
        dL = lagrangian.delta()

        # infinitesimal action integral
        dS = dL + inf_work
        if record is not None:
            record("dL", dL)
            record("dW", inf_work)
            record("dS", dS)

        # apply manifold kinematic substitutions
        stage = "manifold_rules"
        dS = apply_manifold_rules(dS, variables)
        if record is not None:
            record("manifold_rules", dS)

        stage = "simplify"
        dS = full_simplify(dS)
        if record is not None:
            record("simplify", dS)

        # integration by parts
        stage = "ibp"
        try:
            dS = _integrate_by_parts(dS, variation_vector_dots, record)
        except (AlgebraicError, NonLinearError) as err:
            raise type(err)(
                f"compute_eom: while integrating by parts (stage ibp, targets"
                f" {', '.join(f'{t}' for t in variation_vector_dots)}): {err}"
            ) from err
        if record is not None:
            record("ibp", dS)

        # expand
        stage = "expand"
        dS = expand(dS)
        if record is not None:
            record("expand", dS)

        # extract equations of motion
        stage = "extract"
        try:
            eom = _separate_variations(dS, variation_vectors, record)
        except _ExtractionFailure as failure:
            # retold with L when it depends on accelerations; otherwise the δS message
            raise failure.retold(dS, variation_vectors, lagrangian, variables) from (
                failure.engine
            )
        if debug:
            for _, eq in eom.values():
                check_tree(eq)

        stage = "stray_check"
        # a variation symbol that survives extraction belongs to no listed variable or param
        wrapped: dict[str, str] = {}  # δ(d/dt(x)) built by hand → x
        stray = _stray_variation_symbols(dS, allowed, param_names, wrapped)
        for _, eq in eom.values():
            stray.update(_stray_variation_symbols(eq, allowed, param_names, wrapped))
        if stray:
            symbols = ", ".join(f"'{s}'" for s in sorted(stray))
            names = ", ".join(f"'{n}'" for n in sorted(set(stray.values())))
            message = (
                f"compute_eom: δS still contains the variation symbols {symbols} of the symbols"
                f" {names}, which are neither entries of SystemVariables nor declared in params"
            )
            if any(sym not in wrapped for sym in stray):
                message += (
                    "; for each symbol, list it in SystemVariables, declare it in params=..., or"
                    " mark it 'Constant'"
                )
            for sym, leaf in sorted(wrapped.items()):
                message += (
                    f"; '{sym}' is the variation of a time derivative, which the engine never"
                    f" builds: write the variation of the configuration variable itself,"
                    f" {leaf}.delta() (the variation of the velocity is {leaf}.t_diff().delta(),"
                    " built as d/dt of the variation, and is not allowed in inf_work)"
                )
            raise ValueError(message)
        if not variation_vectors:
            raise ValueError(
                "compute_eom: no configuration variables listed in SystemVariables; a system"
                " with no degree of freedom has no equation of motion"
            )
        return eom
    except Exception as err:
        if trace is not None:
            trace._fail(_failed_stage(trace, stage, err), err)
        raise

    def linearize(
    eom: dict[str, tuple[Expr, Expr]],
    variables: SystemVariables,
    inputs: Sequence[Expr] | None = None,
    params: Sequence[Expr] = (),
    *,
    trace: LinearizationTrace | None = None,
) -> LinearizedSystem:
    """Linearize the equations of motion along an arbitrary trajectory.

    Parameters
    ----------
    eom : dict
        Output of ``compute_eom``: ``{str(variation_vec): (variation_vec, eom_expr)}``.
    variables : SystemVariables
        The configuration variables used for ``compute_eom``.
    inputs : list[Scalar | Vector], optional
        Input symbols (forces, torques, thrust). Their variations form δu.
    params : list, optional
        The prescribed parameters passed to ``compute_eom(..., params=...)``. Prescribed
        parameters are not supported by ``linearize`` yet: a term carrying the variation
        of a declared param raises ``AlgebraicError`` saying so (without ``params`` the
        message cannot tell a param from a missing input or a missing ``Constant``).
    trace : LinearizationTrace, optional
        Keyword only. Filled per dynamic row with δE, the partition buckets, the raw
        coefficients (before ``full_simplify`` and before the mass blocks are negated)
        and the final blocks; see ``LinearizationTrace``. Cleared when the call
        starts; after an exception ``trace.failed_at`` names the stage that raised.

    Returns
    -------
    LinearizedSystem
        Blocks of ``M δẋ = A δx + B δu`` (see the module docstring for the sign
        convention and the kinematic rows).

    Raises
    ------
    TypeError
        Invalid ``variables`` or ``inputs`` (not plain ``Scalar``/``Vector`` leaves, or a
        ``set``/``dict``, whose order would be that of the columns of ``B``),
        a non-``SO3`` matrix configuration, or an equation whose type differs from
        that of its variation vector (a scalar equation under a vector key).
    ValueError
        Constant or duplicate inputs (the input checks are ``check_inputs``, shared with
        ``to_standard_form``), an input that is also a configuration variable
        or a tangent vector (``Ω``, ``ω``) whose variation is already a state, an input
        printed like a velocity, an acceleration or a different node of the equations
        (a constant ``g`` of ``L`` given as ``Scalar("g")``, another class, ``attr`` or
        size, or an operation node such as ``d/dt(l)``), or
        ``eom`` keys that do not match ``variables``. A stray variation symbol in an
        equation also surfaces as the engine's ``ValueError`` (δ of a variation is
        not representable).
    AlgebraicError
        An input whose rate occurs in the equations (a param of ``compute_eom`` given as
        an input, ``check_inputs``). A term of δE carries no perturbation symbol, more
        than one (a nonlinear or incompletely distributed term), or one only inside a
        non-canonical calculus node, or a coefficient could not be factored.
    """
    if trace is not None:
        trace._reset()
    stage = "validation"
    try:
        check_variables(variables, caller="linearize")
        cfg_vars, cfg_perts, vel_perts = perturbation_variables(variables)
        _check_eom(eom, variables)
        param_names = _param_names(params)
        debug = debug_enabled()
        if debug:
            for _, eq in eom.values():
                check_tree(eq)
        record = stage_recorder(trace, "linearize")
        states = cfg_perts + vel_perts
        dstates = [s.t_diff() for s in states]
        inputs = check_inputs(inputs, variables, [eq for _, eq in eom.values()], "linearize")
        input_perts = [u.delta() for u in inputs]
        dvel_perts = dstates[len(cfg_perts) :]

        col_types = {}
        for sym in states + dstates + input_perts:
            col_types[str(sym)] = sym.type

        rows: list[str] = []
        row_types: dict[str, ExprType] = {}
        M: dict[str, dict[str, Expr]] = {}
        A: dict[str, dict[str, Expr]] = {}
        B: dict[str, dict[str, Expr]] = {}
        blocks = _Blocks(rows, row_types, M, A, B, dstates, states, input_perts)

        for i, var in enumerate(cfg_vars):
            _kinematic_row(blocks, var, cfg_perts[i], vel_perts[i], dstates[i])

        # Priority order for assigning a term to its perturbation symbol: the most
        # deeply wrapped symbols first, so that a term in d/dt(δv) is never tested
        # for δv (which would raise inside has_algebraic).
        priority = dvel_perts + vel_perts + cfg_perts + input_perts
        all_perts = priority + [d for d in dstates[: len(cfg_perts)]]
        n_mass = len(dvel_perts)
        n_state = n_mass + len(vel_perts) + len(cfg_perts)

        for label, (var_vec, eq) in eom.items():
            stage = f"row[{label}]"
            _dynamic_row(
                blocks,
                label,
                var_vec,
                eq,
                priority,
                all_perts,
                n_mass,
                n_state,
                param_names,
                record,
                debug,
            )

        return LinearizedSystem(
            rows=rows,
            states=states,
            dstates=dstates,
            inputs=input_perts,
            M=M,
            A=A,
            B=B,
            row_types=row_types,
            col_types=col_types,
        )
    except Exception as err:
        if trace is not None:
            trace._fail(_failed_row_stage(trace, stage), err)
        raise

    def to_standard_form(
    eom_dict: dict[str, tuple[Expr, Expr]],
    variables: SystemVariables,
    inputs: Sequence[Expr] | None = None,
) -> dict[str, StandardFormEquation]:
    """Decompose EOM into standard manipulator form.

    Parameters
    ----------
    eom_dict : dict
        Output of ``compute_eom()``:
        ``{str(variation_vec): (variation_vec, eom_expr)}``.
    variables : SystemVariables
        Configuration variables (used to derive acceleration variables).
    inputs : list[Scalar | Vector], optional
        Input variables (forces, torques). Default (``None``): no inputs. Validated by
        ``check_inputs``, exactly as in ``linearize``: a ``TypeError`` for an entry that
        is not a plain ``Scalar``/``Vector`` leaf, one leaf instead of a sequence, or a
        ``set``/``dict`` (the order of *inputs* is the order of the input columns), a
        ``ValueError`` for a constant or duplicate input, a configuration variable, a
        tangent or variation vector (``ω``, ``ξ``, ``Ω``, ``η``), or an input printed like
        a velocity or acceleration, or like a different node of the equations (a constant
        ``g`` of ``L`` given as ``Scalar("g")``, another class, ``attr`` or size, or an
        operation node such as ``d/dt(l)``), since leaves are matched by printed name; an
        ``AlgebraicError`` for an input whose rate occurs in the equations (a param of
        ``compute_eom``). A non-dict *eom_dict* raises ``TypeError``.

    Returns
    -------
    dict[str, StandardFormEquation]
        Keyed by the same variation vector names as *eom_dict*.

    Notes
    -----
    On S² the equation ``E = 0`` of a variable ``q`` is only meaningful on the tangent
    plane, ``(I − qqᵀ) E = 0``: ``E`` is the coefficient of ``ξ ⊥ q`` and in general has
    a component along ``q`` (from the forcing, from ``ω × c``, from ``A ω̇``, …). The
    blocks returned here are the terms of ``E`` as derived, not projected. To solve for
    ``ω̇`` solve ``(I − qqᵀ)(M ω̇ + f + Σ G u) = 0`` with ``ω̇ ⊥ q``; the unprojected
    3×3 solve gives ``q · ω̇ ≠ 0`` and a trajectory that leaves the sphere. The same
    holds for the rows of ``linearize``.

    Errors name the equation and the term: a term that holds an acceleration only under
    a further time derivative (a jerk ``d/dt(ẍ)``) raises ``AlgebraicError`` saying the
    equation is not second order; a term bilinear in two accelerations raises
    ``NonLinearError``. With ``GEOMECH_DEBUG=1`` the blocks of each equation are logged
    on the ``geomech`` logger and ``check_tree`` runs on every equation and block.
    """
    if not isinstance(eom_dict, dict):
        raise TypeError(
            f"to_standard_form: eom must be the dict returned by compute_eom, got {type(eom_dict)}"
        )
    inputs = check_inputs(
        inputs, variables, [eq for _, eq in eom_dict.values()], "to_standard_form"
    )

    accel_vars = _get_accel_vars(variables)
    debug = debug_enabled()
    record = stage_recorder(None, "to_standard_form")

    result = {}
    for key, (var_vec, eom_expr) in eom_dict.items():
        if debug:
            check_tree(eom_expr)
        sf = _extract_single(eom_expr, accel_vars, inputs, key)
        if record is not None:
            for name, block in sf.M.items():
                record(f"M[{key}][{name}]", block)
            record(f"f[{key}]", sf.f)
            for name, block in sf.G.items():
                record(f"G[{key}][{name}]", block)
        if debug:
            for block in (*sf.M.values(), sf.f, *sf.G.values()):
                check_tree(block)
        result[key] = sf

    return result
