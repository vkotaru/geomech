    layout ¶

    StateLayout: how the symbols of a system map to flat numeric arrays.

    One layout is the single source of truth for the generated code and its callers:

    ========================== =================== ================= ==================== Variable Configuration slot Velocity slot Acceleration symbol ========================== =================== ================= ==================== s: Scalar (R) s (1) ṡ (1) s̈ x: Vector (R³) x (3) ẋ (3) ẍ q: S2 q (3, unit) ω (3, ⊥ q) ω̇ R: SO3 R (9, row-major) Ω (3) Ω̇ ========================== =================== ================= ====================

    state holds every configuration slot in variable order (SystemVariables order: scalars, vectors, matrices), then every velocity slot in the same order. a stacks the accelerations in the same order, u the inputs in the given order (scalars 1, vectors 3) and p is a dict keyed by str(symbol) of every parameter.

    Slot(symbol, key, name, kind, array, shape, start=None, stop=None, manifold='') dataclass ¶

    One symbol of a layout.

    array is the argument that holds it ("state", "a", "u" or "p"), start:stop its entries there (None for a parameter), shape its numeric shape ((), (3,), (3, 3); an SO(3) point occupies 9 row-major entries) and name the Python identifier the generated code binds it to. manifold is "R", "R3", "S2" or "SO3" for the slots of a configuration variable.

    StateLayout(variables, inputs=(), params=()) ¶

    How the configuration, velocity, acceleration, input and parameter symbols of a system map to the flat arrays state, a, u and the dict p.

    One layout serves every module of a system: build it with the SystemVariables and the inputs list (same order) passed to to_standard_form and linearize, and generate the standard-form and the linearization module from it (generate_module checks the linearization against it). pack/unpack convert between named slot values and the flat state.

    Parameters:

    Name Type Description Default
    variables SystemVariables

    the SystemVariables of the system (scalars, then vectors, then matrices; each matrix an SO3).

    		 required
    inputs Sequence[Expr]

    input leaves (Scalar/Vector), stacked into u in this order; validated by geomech.dynamics.eom.check_inputs (an ordered sequence, no constant, no configuration variable, nothing printed like a velocity or acceleration), the check of to_standard_form and linearize.

    		 ()
    params Sequence[Expr]

    named constants (any Scalar/Vector/Matrix leaf that is neither a configuration variable nor an input, or the TimeDerivative of one for a prescribed rate), passed as p[str(symbol)]. Numeric literals are inlined by the code generator and are not parameters; tangent and variation vectors (ω, ξ, Ω, η) are rejected. collect_params lists them.

    		 ()

    Raises TypeError/ValueError naming the symbol for an invalid entry and for two symbols that print alike (str is the identity of a symbol in the engine and the key of p).

    self,
    variables: SystemVariables,
    inputs: Sequence[Expr] = (),
    params: Sequence[Expr] = (),

    if not isinstance(variables, SystemVariables):
        raise TypeError(
            f"StateLayout: variables must be a SystemVariables, got {type(variables).__name__}"
        )
    check_variables(variables, caller="StateLayout")
    self.variables = variables
    # the input checks of to_standard_form/linearize, without equations to compare
    self.inputs = tuple(check_inputs(inputs, variables, (), "StateLayout"))
    self.params = tuple(_as_sequence(params, "params"))
    self._slots: dict[str, Slot] = {}
    self._names: set[str] = set()

    self.velocity: list[Slot] = []
    self.acceleration: list[Slot] = []
    self._build_state()
    self.input_slots = self._build_inputs()
    self.param_slots = self._build_params()

    def env_from_arrays(self, state, a=None, u=None, p=None) -> dict:
    """The ``Evaluator`` env of flat arrays: the inverse of the ``*_from_env`` methods."""
    env: dict[str, Any] = {}
    groups = [(self.configuration + self.velocity, state), (self.acceleration, a)]
    groups.append((self.input_slots, u))
    for slots, arr in groups:
        if arr is None:
            continue
        arr = np.asarray(arr, dtype=float).reshape(-1)
        for s in slots:
            env[s.key] = _column(arr[s.slice], s.shape)
    for key, val in (p or {}).items():
        env[key] = val if np.isscalar(val) else _column(np.asarray(val, float), None)
    return env

    def pack(self, values: dict | None = None, /, **slots) -> np.ndarray:
    """The flat ``state`` from named slot values.

    Keys are the slot names of ``unpack`` (the Python identifiers of the generated
    code: ``x_L``, ``q``, ``R``, ``x_L_dot``, ``omega_q``, ``Omega_R``, ``s_dot`` …),
    as keyword arguments, or those names or the printed symbols (``"\\omega_{q}"``)
    as keys of *values*. Every configuration slot is required; a velocity slot that
    is not given is zero. ``R`` may be a 3×3 matrix or its 9 row-major entries.
    Values are not projected onto the manifold: ``simulate`` and ``lqr`` check
    ``|q| = 1``, ``q·ω = 0`` and ``RᵀR = I``.

    Raises ``KeyError`` for an unknown or missing configuration slot and
    ``ValueError`` for a value of the wrong size.
    """
    given: dict[str, Any] = {}
    for key, val in [*(values or {}).items(), *slots.items()]:
        slot = self._state_slot(str(key) if not isinstance(key, str) else key)
        if slot.key in given:
            raise ValueError(f"StateLayout.pack: '{slot.name}' given twice")
        given[slot.key] = val
    missing = [s.name for s in self.configuration if s.key not in given]
    if missing:
        raise KeyError(f"StateLayout.pack: no value for the configuration slot(s) {missing}")
    out = np.zeros(self.n_state)
    for s in self.configuration + self.velocity:
        if s.key not in given:
            continue
        val = np.asarray(given[s.key], dtype=float).reshape(-1)
        if val.size != s.size:
            raise ValueError(
                f"StateLayout.pack: '{s.name}' needs {s.size} entries (shape"
                f" {s.shape}), got {val.size}"
            )
        out[s.slice] = val
    return out

    def params_from_env(self, env: dict) -> dict:
    """``p`` from an ``Evaluator`` env (vectors as ``(3,)`` arrays)."""
    out: dict[str, Any] = {}
    for s in self.param_slots:
        val = env[s.key]
        out[s.key] = float(val) if not s.shape else np.asarray(val, float).reshape(s.shape)
    return out

    def to_dict(self) -> dict:
    """The layout as plain data (lists, dicts, strings, ints), embedded in generated

        "n_state": self.n_state,
        "n_config": self.n_config,

        "inputs": [s.to_dict() for s in self.input_slots],

    }

    def unpack(self, state) -> dict[str, np.ndarray]:
    """``{slot name: value}`` of a flat ``state`` (or of a ``(..., n_state)`` array,
    such as ``Trajectory.state``): the inverse of ``pack``. Scalars have shape ``()``,
    vectors ``(3,)`` and ``R`` ``(3, 3)`` (with the leading axes of *state*)."""
    x = np.asarray(state, dtype=float)
    if x.shape[-1:] != (self.n_state,):
        raise ValueError(
            f"StateLayout.unpack: state must have {self.n_state} entries on its last"
            f" axis, got shape {x.shape}"
        )
    lead = x.shape[:-1]
    return {
        s.name: x[..., s.slice].reshape(lead + s.shape)
        for s in self.configuration + self.velocity
    }

    def collect_params(exprs, variables: SystemVariables, inputs: Sequence[Expr] = ()) -> list[Expr]:
    """The symbols of *exprs* that a ``StateLayout(variables, inputs)`` does not cover.

    *exprs* is what the system is made of: ``[L, dW]`` (or ``[L]`` plus the
    equations), the dict returned by ``compute_eom`` or by ``to_standard_form``, a
    ``LinearizedSystem``, one ``Expr``, or an iterable of these. Anything else (a number,
    a string, an object without symbols) raises ``TypeError`` rather than giving ``[]``.

    Numeric literals and the zero/identity constants are left out (they are inlined), as
    are the configuration, velocity and acceleration symbols of *variables*, their
    tangent and variation vectors (``ω``, ``ξ``, ``Ω``, ``η``, which ``δW`` and
    ``compute_eom`` hold) and the *inputs*. The rest, sorted by printed name, are the
    parameters to pass as ``params``.
    """
    known = StateLayout(variables, inputs)
    found: dict[str, Expr] = {}
    _walk(exprs, found)
    return [
        sym
        for key, sym in sorted(found.items())
        if known.slot(key) is None
        and not is_literal_leaf(sym)
        and not isinstance(sym, (TS2, TSO3))
    ]

    def is_literal_leaf(node) -> bool:
    """A number, or a zero or identity constant: inlined in the generated code."""
    if is_number_literal(node):
        return True
    if isinstance(node, (Scalar, Vector, Matrix)) and node.is_zero:
        return True
    return isinstance(node, Matrix) and node.flags.is_identity
