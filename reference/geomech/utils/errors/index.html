    AlgebraicError(msg='') ¶

    Bases: Exception

    Expression cannot be algebraically factored as requested.

    Raised when an operation is mathematically impossible, not merely unimplemented — e.g. extracting a linear vector coefficient from an outer product (rank-1 matrix) that does not factor as C * q.

    ExpressionMismatchError(operation='', ltype=None, rtype=None, lhs=None, rhs=None, *, msg=None) ¶

    Bases: Exception

    Operand types do not fit the operation.

    Built from the operation name and the two operand types; when the operands themselves are passed (lhs/rhs) the message names them, so that the failing node can be found in a long Lagrangian:

    Dot cannot combine SCALAR 'm' and VECTOR 'x'

    ExpressionMismatchError.unary(op, expected, expr) builds the one-operand form (Hat expects a VECTOR, got SCALAR 'm'); msg replaces the message outright.

    def __init__(self, operation="", ltype=None, rtype=None, lhs=None, rhs=None, *, msg=None):
    if msg is None:
        if ltype is not None and rtype is not None and (lhs is not None or rhs is not None):
            lpart = _type_name(ltype) + (" " + _operand_str(lhs) if lhs is not None else "")
            rpart = _type_name(rtype) + (" " + _operand_str(rhs) if rhs is not None else "")
            msg = f"{operation} cannot combine {lpart} and {rpart}"
        elif ltype is not None and rtype is not None:
            msg = (
                operation
                + " cannot be performed between "
                + _type_name(ltype)
                + " and "
                + _type_name(rtype)
            )
        else:
            msg = (operation + ": " if operation else "") + "operation cannot be performed"
    super().__init__(msg)

    @classmethod
def unary(cls, operation: str, expected, expr) -> "ExpressionMismatchError":
    """``{operation} expects a {expected}, got {type} '{expr}'`` for a one-operand node."""
    return cls(
        msg=(
            f"{operation} expects a {_type_name(expected)},"
            f" got {_type_name(expr.type)} {_operand_str(expr)}"
        )
    )

    InvariantError(msg='') ¶

    Bases: Exception

    An expression tree violates a structural invariant of the engine.

    Raised by geomech.check_tree (geomech/utils/invariants.py); the message names the invariant and the offending subtree, with its path from the root (root.R.0.L: right child, first addend, left child).
