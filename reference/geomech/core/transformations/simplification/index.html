    simplification ¶

    Simplification passes.

    simplify(expr) — one pass: pull (hoist scalars), vector_rules (geometric identities), then _eliminate (bottom-up zeros, identities and numeric folding, the rules below). full_simplify(expr) — expand once, then simplify until the printed tree stops changing (at most max_iter passes; hitting the cap warns).

    Rules of _eliminate (name, identity, hypothesis the code checks). "Zero" means the operand is flagged zero (Zero, ZeroVector, ZeroMatrix, a Constant symbol's variation...), "one" a numeric leaf with value 1, "identity" a leaf flagged Identity.

    simplify.add_fold Add: zeros dropped, numeric leaves summed, like terms merged; float sums within 1e-12 of the largest magnitude are cancelled to 0 (_CANCEL_RTOL) simplify.vadd_fold VAdd: zeros dropped, like terms merged simplify.madd_fold MAdd: zeros dropped, like terms merged

    Like terms (all three folds): an addend is split into a number (the product of every numeric literal in its flattened Mul chain and, for vectors and matrices, in the scalars of its SVMul/SMMul), its other scalar factors and its vector/matrix base; two addends merge when their bases are equal and their factors are equal as multisets (x(2)y + xy(3) → xy(5), v a + v a(-1) → 0, (vᵀw)s + s(vᵀw) → (vᵀw)s(2)). "Equal" is term_key: the operands of a Dot and of an inner product aᵀb commute (aᵀb s − bᵀa s → 0) and so do the factors of a Mul; every other product keeps its order. Grouping is one pass over the addends, keyed by term_key. Numeric literals are anonymous numbers only: a named Scalar("m", value=2) is a symbol and is never folded (decision D1); its value is used by geomech.numeric only. simplify.mul_fold Mul: a zero factor gives 0, a factor one is dropped, numeric factors of a Mul chain are multiplied into one number placed last; a float with an integer value becomes an int ((-1.0) → (-1))

    Every numeric literal leaf is put in the spelling Number gives it ((2.0) → (2), Scalar("0.5", value=0.5) → (0.5)), so equal numbers print, and compare, the same. simplify.svmul_zero v·0 = 0·s = 0     full_simplify(expr, max_iter=10) ¶

    Expand once, then loop simplify until convergence.

    Parameters¶

    max_iter : int Safety cap on the number of passes (default 10). Hitting it emits a RuntimeWarning ("no confirmed fixed point after N passes") naming the expression: the result may be unsimplified. A pass that changes nothing ends the loop, so the warning fires only when the last allowed pass still changed the expression; that last result may already be the fixed point, which only one more pass could confirm (hence "confirmed").

    def full_simplify(expr, max_iter=10):
    """Expand once, then loop simplify until convergence.

    Parameters
    ----------
    max_iter : int
        Safety cap on the number of passes (default 10). Hitting it emits a
        ``RuntimeWarning`` ("no confirmed fixed point after N passes") naming the
        expression: the result may be unsimplified. A pass that changes nothing ends the
        loop, so the warning fires only when the last allowed pass still changed the
        expression; that last result may already be the fixed point, which only one more
        pass could confirm (hence "confirmed").
    """
    expr = expand(expr)
    for _ in range(max_iter):
        prev = expr
        expr = simplify(expr)
        if str(expr) == str(prev):
            break
    else:
        why = (
            "max_iter=0: no simplify pass ran"
            if max_iter <= 0
            else f"the last pass still changed the expression, so no fixed point after"
            f" {max_iter} passes was confirmed by an unchanged pass"
        )
        warnings.warn(
            f"full_simplify: no confirmed fixed point after {max_iter} passes ({why});"
            f" result may be unsimplified: {expr!r}",
            RuntimeWarning,
            stacklevel=2,
        )
    return expr

    def simplify(expr):
    """Pull scalars, apply vector identities, then eliminate zeros and
    combine numeric constants — single call does everything."""
    expr = pull(expr)
    expr = vector_rules(expr)
    return _eliminate(expr)

    term_key(expr) ¶

    A canonical string for expr up to the commutativity the like-term merge knows.

    Two expressions have the same key exactly when they are the same tree except that the operands of a Dot may be swapped, the factors of a Mul chain may be reordered, and an inner product aᵀb of two columns (VVMul(Transpose(a), b)) may be written bᵀa (at any depth). Every other node compares its operands in order, and a leaf by class and printed name. The key is injective on such classes: a leaf is written Class#len#name (the length makes it self-delimiting), a node Class(key,key,...) with the operand keys sorted for Dot and the flattened Mul factors, and an inner product VVMul.inner(key,key) with the keys of its two columns sorted.

    def term_key(expr) -> str:
    """A canonical string for *expr* up to the commutativity the like-term merge knows.

    Two expressions have the same key exactly when they are the same tree except that the
    operands of a ``Dot`` may be swapped, the factors of a ``Mul`` chain may be reordered,
    and an inner product ``aᵀb`` of two columns (``VVMul(Transpose(a), b)``) may be
    written ``bᵀa`` (at any depth). Every other node compares its operands in order, and a leaf
    by class and printed name. The key is injective on such classes: a leaf is written
    ``Class#len#name`` (the length makes it self-delimiting), a node
    ``Class(key,key,...)`` with the operand keys sorted for ``Dot`` and the flattened
    ``Mul`` factors, and an inner product ``VVMul.inner(key,key)`` with the keys of its
    two columns sorted.
    """
    nodes = getattr(expr, "nodes", None)
    cls = type(expr).__name__
    if not nodes:
        name = str(expr)
        return f"{cls}#{len(name)}#{name}"
    if isinstance(expr, Mul):
        keys = sorted(term_key(f) for f in flatten_mul(expr))
    elif (
        isinstance(expr, VVMul)
        and expr.type == ExprType.SCALAR
        and isinstance(expr.left, Transpose)
    ):
        # the inner product aᵀb of two columns is symmetric: aᵀb = bᵀa
        keys = sorted((term_key(expr.left.expr), term_key(expr.right)))
        return "VVMul.inner(" + ",".join(keys) + ")"
    elif isinstance(expr, Dot):
        keys = sorted(term_key(n) for n in nodes)
    else:
        keys = [term_key(n) for n in nodes]
    return cls + "(" + ",".join(keys) + ")"
