    expansion ¶

    Distribute multiplication over addition (expand products).

    Bottom-up traversal: expand children first, then distribute at the current node. Single pass.

    Distribution rules (name, identity; none needs a hypothesis: they are bilinearity of each product and linearity of Hat). A rule fires only when an operand is a sum.

    expand.mul_over_add Mul over Add → Add (scalar) expand.dot_over_vadd Dot over VAdd → Add (scalar from vectors) expand.cross_over_vadd Cross over VAdd → VAdd (vector) expand.svmul_over_sum SVMul over VAdd/Add → VAdd (vector, left=vector right=scalar) expand.row_svmul_over_sum a scaled row rᵀ s over a sum of rows or an Add scalar expand.mvmul_over_sum MVMul over MAdd/VAdd → VAdd (vector) expand.row_mvmul_over_sum a row times a matrix, rᵀ M, over a sum of rows on the left or an MAdd on the right expand.smmul_over_sum SMMul over MAdd/Add → MAdd (matrix, left=matrix right=scalar) expand.mmmul_over_madd MMMul over MAdd → MAdd (matrix) expand.vvmul_outer_over_vadd VVMul over VAdd → MAdd (outer product v wᵀ; a VAdd in v or inside Transpose(w)) expand.vvmul_inner_over_vadd VVMul over VAdd → Add (inner product vᵀ w; a VAdd inside Transpose(v) or in w) expand.hat_over_vadd Hat(a + b) = Hat(a) + Hat(b) expand.vee_over_madd Vee(A + B) = Vee(A) + Vee(B)

    Transpose is not expanded on its own (Transpose(MAdd) and Transpose(VVMul) are left intact); the VVMul rule is the only place that looks through a Transpose(VAdd) factor, because a bare VAdd of transposed vectors is not a valid VVMul operand.

    Row vectors that are not a Transpose node (aᵀK, s aᵀ, aᵀ + bᵀ) are distributed in place and keep their row form: (aᵀ(K + J)) b expands to aᵀK b + aᵀJ b. Inside such a row, a Transpose(VAdd) factor is split the same way as in a VVMul.

    def expand(expr):
    """Distribute every product over sums, bottom up (rules in the module docstring)."""
    match expr:
        # --- N-ary additions: expand each term ---
        case Add(nodes=nodes):
            return Add(*[expand(n) for n in nodes])

        case VAdd(nodes=nodes):
            return VAdd(*[expand(n) for n in nodes])

        case MAdd(nodes=nodes):
            return MAdd(*[expand(n) for n in nodes])

        # --- Scalar * Scalar ---
        case Mul():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, Mul, Add, Add, Add, "expand.mul_over_add", expr)

        # --- Dot product (vector x vector → scalar) ---
        case Dot():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, Dot, Add, VAdd, VAdd, "expand.dot_over_vadd", expr)

        # --- Cross product (vector x vector → vector) ---
        case Cross():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, Cross, VAdd, VAdd, VAdd, "expand.cross_over_vadd", expr)

        # --- Scalar * Vector  (left=vector, right=scalar) ---
        case SVMul() if is_row_vector(expr.left):
            return _expand_row_svmul(expr)

        case SVMul():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, SVMul, VAdd, VAdd, Add, "expand.svmul_over_sum", expr)

        # --- Matrix * Vector ---
        case MVMul() if expr.left.type == ExprType.VECTOR:
            return _expand_row_mvmul(expr)

        case MVMul():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, MVMul, VAdd, MAdd, VAdd, "expand.mvmul_over_sum", expr)

        # --- Scalar * Matrix  (left=matrix, right=scalar) ---
        case SMMul():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, SMMul, MAdd, MAdd, Add, "expand.smmul_over_sum", expr)

        # --- Matrix * Matrix ---
        case MMMul():
            l, r = expand(expr.left), expand(expr.right)
            return _distribute(l, r, MMMul, MAdd, MAdd, MAdd, "expand.mmmul_over_madd", expr)

        # --- Vector * Vector (outer product → matrix, inner product → scalar) ---
        case VVMul():
            return _expand_vvmul(expr)

        # --- Unary ops: recurse into child ---
        # Hat is linear: Hat(a + b) = Hat(a) + Hat(b)
        case Hat():
            inner = expand(expr.expr)
            if isinstance(inner, VAdd):
                return rule("expand.hat_over_vadd", expr, MAdd(*[Hat(n) for n in inner.nodes]))
            return Hat(inner)

        # Vee is linear: Vee(A + B) = Vee(A) + Vee(B)
        case Vee():
            inner = expand(expr.expr)
            if isinstance(inner, MAdd):
                return rule("expand.vee_over_madd", expr, VAdd(*[Vee(n) for n in inner.nodes]))
            return Vee(inner)

        case Variation():
            return calculus_node(Variation, expand(expr.expr))

        case TimeDerivative():
            return calculus_node(TimeDerivative, expand(expr.expr))

        case TimeIntegral():
            return TimeIntegral(expand(expr.expr))

        # --- Leaves and everything else ---
        case _:
            return expr
