# Support

- **Questions and how-to:** open a GitHub issue with the question template, or read the
  documentation first: the pipeline, conventions and troubleshooting pages answer most
  questions, and the troubleshooting page lists every error message with its cause.
- **Bugs:** open an issue with the bug template (a minimal system definition and the
  `check_eom` output make a report actionable).
- **Wrong equations** are treated as the highest-priority bugs.

geomech is maintained on a best-effort basis by its author. Issues are usually answered
within a couple of weeks.
